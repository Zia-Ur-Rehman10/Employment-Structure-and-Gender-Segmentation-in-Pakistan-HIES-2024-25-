# Employment-Structure-and-Gender-Segmentation-in-Pakistan-HIES-2024-25-
Clean and transform official Household Integrated Economic Survey (HIES) employment tables into a tidy analytical dataset and conduct regional, gender, and income-based employment analysis in Pakistan.
**Objectives**
Data cleaning in R
Excel import using readxl
Wrangling with dplyr and tidyr
Visualization using ggplot2
Gender-gap construction
Heatmap analysis
Urban–rural comparison
Unsupervised clustering (K-means)
**Key findings**
Household heads in wage employment are overwhelmingly male across Pakistan.
Female wage employment is concentrated among non-head household members.
Strong regional heterogeneity exists across provinces.
Urban regions cluster into formal wage-based labor regimes.
Rural regions remain family-labor dominant.
Punjab Urban emerges as a distinct entrepreneurial female labor market cluster.
