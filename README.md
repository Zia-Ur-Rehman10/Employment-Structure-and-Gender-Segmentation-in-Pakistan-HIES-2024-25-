# Employment-Structure-and-Gender-Segmentation-in-Pakistan-HIES-2024-25-
**Project Overview**
Using HIES 2024–25 data from Pakistan Bureau of Statistics, this project investigates labor market inequality in Pakistan across three dimensions:

- gender inequality
- occupational inequality
- regional/spatial inequality

**The project develops:**

- gender wage gap estimates
- occupational income rankings
- provincial competitiveness mapping
- urban wage premium analysis
- Women’s Economic Opportunity Index (WEOI)

**Tools:**

- RStudio
- tidyverse 
- ggplot2
- survey data analytics
- economic visualization

**Key Findings:**

**1. Large occupational gender gaps persist**

Female earnings remain substantially below male earnings across most occupations.

**2. Urban wage premiums are substantial**

Urban workers earn significantly more than rural workers, especially in lower-skilled occupations.

**3. Provincial specialization exists**

Different provinces dominate different occupational wage categories.

**4. Women’s economic opportunity is urban concentrated**

Urban regions outperform rural regions on composite female opportunity metrics.
